# StarBintang

Website galeri foto dan video dengan tema kuning, merah, gradasi biru, dan putih.

**Mulai cepat:** buka `index.html` di VS Code. Untuk membuat upload tersimpan online dan terlihat oleh orang lain, ikuti semua langkah di `SETUP.md` untuk Supabase + Netlify.

Upload online tidak aktif sebelum Supabase dikonfigurasi.
