# StarBintang — website galeri kenangan

Website ini dibuat untuk dibuka di VS Code, lalu dipublikasikan agar orang lain bisa melihat galeri dan menambahkan foto/video baru. Frontend bisa di-host gratis di Netlify; file dan data disimpan di Supabase, bukan hanya di browser.

## 1. Buka di VS Code

1. Ekstrak `StarBintang.zip`.
2. VS Code → **File → Open Folder** → pilih folder `StarBintang`.
3. Pasang ekstensi **Live Server** (opsional untuk preview). Untuk menjalankan sebagai situs statis lokal, klik kanan `index.html` → **Open with Live Server**.
4. Tanpa konfigurasi Supabase, halaman tampil tetapi upload cloud belum aktif.

## 2. Siapkan penyimpanan online Supabase

1. Buat akun dan project di https://supabase.com/ .
2. Buka **SQL Editor → New query**, lalu jalankan SQL berikut.

```sql
create table if not exists public.memories (
  id bigint generated by default as identity primary key,
  title text not null,
  description text default '',
  file_url text not null,
  file_path text not null,
  media_type text not null check (media_type in ('photo','video')),
  created_at timestamptz not null default now()
);

alter table public.memories enable row level security;

create policy "Public can view memories"
on public.memories for select to anon using (true);

create policy "Public can add memories"
on public.memories for insert to anon
with check (
  char_length(title) between 1 and 90
  and char_length(coalesce(description,'')) <= 500
  and media_type in ('photo','video')
);

-- Website ini belum memiliki login. Agar pengunjung dapat menghapus item,
-- kebijakan DELETE publik akan memberi siapa pun kemampuan menghapus galeri.
-- Karena itu fitur hapus sengaja tidak diaktifkan melalui kebijakan ini.
```

3. Buka **Storage → New bucket**, beri nama persis `starbintang-media`, aktifkan **Public bucket**.
4. Buka kebijakan (Policies) untuk bucket `starbintang-media` dan buat policy berikut:
   - SELECT untuk role `anon`, kondisi `bucket_id = 'starbintang-media'`
   - INSERT untuk role `anon`, kondisi `bucket_id = 'starbintang-media'`

   Jangan buat policy UPDATE/DELETE publik. Catatan: upload anonim berarti siapa pun yang menemukan situs dapat menambah file; batas ukuran dan tipe file juga atur di pengaturan bucket bila tersedia.
5. Buka **Project Settings → API** (atau bagian API Keys). Salin **Project URL** dan **anon/public key**. Jangan pernah menaruh `service_role` key di frontend.
6. Buka `index.html` di VS Code. Cari:
   - `PASTE_SUPABASE_PROJECT_URL_HERE`
   - `PASTE_SUPABASE_ANON_KEY_HERE`

   Ganti dengan Project URL dan anon/public key milik project kamu. Simpan file.

## 3. Publikasikan agar bisa diakses orang lain

### Opsi A — Netlify (paling mudah)
1. Buka https://app.netlify.com/ dan login.
2. Pilih **Add new site → Deploy manually** (nama menu bisa berubah).
3. Seret folder `StarBintang` yang berisi `index.html` ke area deploy. Kalau diminta folder publish, pilih folder yang berisi `index.html`.
4. Netlify memberi URL publik `https://....netlify.app`. Bagikan URL tersebut.
5. Setelah mengubah kode, deploy ulang folder yang sudah diperbarui.

### Opsi B — GitHub Pages
GitHub Pages bisa meng-host tampilan statis, tetapi untuk alur pemula ini Netlify lebih sederhana. Jangan commit kredensial rahasia; Supabase anon/public key memang digunakan di browser, sehingga keamanan harus berasal dari Row Level Security dan Storage Policies.

## 4. Catatan penting

- Foto/video dan judul akan disimpan online dan tampil bagi pengunjung lain setelah Supabase tersambung.
- Galeri ini memakai akses anonim tanpa akun. Siapa pun dapat mengunggah; jangan mengunggah materi pribadi atau milik orang lain tanpa izin. Untuk galeri keluarga/kelas, sebaiknya tambahkan login dan batasi upload.
- Batas di antarmuka: foto 15 MB, video 100 MB. Samakan batas ini dengan pengaturan bucket Supabase.
- Fitur hapus belum diberi akses publik agar orang lain tidak bisa menghapus kenangan sesuka hati. Untuk penghapusan yang aman, tambahkan autentikasi admin.
- Kalau muncul error, periksa URL/key, nama bucket, SQL, dan policy Storage.
